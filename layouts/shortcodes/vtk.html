{{/* Load vtk.js once per page via dynamic import() so errors are catchable. Why NOT ?bundle on esm.sh: Each ?bundle file inlines its own copy of vtk.js internals, creating isolated module registries. The Geometry profile would register the WebGL backend into one registry copy while GenericRenderWindow uses another, so no WebGL backend would ever be found — blank canvas with no error. Why the cascade IS correct here: Non-bundled esm.sh modules use absolute esm.sh URLs for their deps. The browser's ES module cache is keyed by URL, so every vtk.js internal (including the backend registry) is loaded exactly once and shared across all imports, regardless of which top-level module triggered the load. Registry sharing = WebGL backend registered by Geometry profile is seen by GenericRenderWindow. The cascade (100+ small requests) is slow on the first visit but everything is immutably cached thereafter. */}} {{- if not (.Page.Store.Get "vtkjs") -}} {{- .Page.Store.Set "vtkjs" true -}} {{- end -}}
