My happy place as an aerodynamicist is the wind tunnel. So far I have been to:
+ HMG Aero-Acoustics Wind Tunnel in Korea
+ FKFS Wind Tunnel in Germany
+ Honda's HALO in Ohio, USA
+ Ford's Rolling Road Wind Tunnel in Michigan, USA
+ WindShear in North Carolina, USA
+ ARC Scale Wind Tunnel in Indy 

I have been meaning to build one for myself to test small objects and calibrate different measurement device I might create in the future for a very long time. I would like to be measure pressure, force and do some flow visualization inside of the tunnel. 

There are three different things that you must consider:
+ Design
+ Manufacturing
+ Electronics 

I will write more about these categories as I move along with my project. A prototype will also be created first so that I can see first hand what the core challenges are.The prototype will be much smaller than the actual product and it will give me enough practice to fabricate the real thing. 

If someone do end up reading these posts, I hope you understand that this is more or less a blog. I guess it wouldn't be wrong to call it an engineering diary of sort.
